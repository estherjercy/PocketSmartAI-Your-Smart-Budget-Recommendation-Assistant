# PocketSmart AI - Your Smart Budget & Recommendation Engine

PocketSmart AI is a lightweight FastAPI-based backend application designed to provide smart budget analysis and personal financial recommendations.

## Features
- **FastAPI Integration:** Fast and efficient asynchronous API processing.
- **Budget Tracking:** Evaluates income, expenses, and savings goals.
- **Automated Recommendations:** Offers customized financial guidance based on spending limits.
